About me

Professional focused on data, cloud and BI

At Babel I built end-to-end ETL processes with Azure Data Factory and SQL Server and Power BI dashboards for financial and industrial clients. In September 2026 I completed the MSc in Data Science, Big Data & Business Analytics at Universidad Complutense de Madrid.

Data Engineering · Real-Time · ML in production

Madrid Commuter Rail Delay Prediction

Renfe reports delays only once they are happening and publishes no history. I built the 24/7 capture system that creates that history and the public web app that turns it into an arrival prediction. Master's thesis (UCM), team of three: my part was the infrastructure, data capture and the app.

Python GTFS-Realtime AEMET API Parquet systemd · Linux FastAPI Databricks · MLflow LightGBM rclone
  • 12 million records in 92 days, captured every minute on a ~€5/month server
  • Immutable raw layer, Parquet analytics layer and daily cloud backup
  • Content monitoring: alert within 10 minutes if a source stops making sense
  • LightGBM model: error down from 283.2 to 147.7 s vs historical baseline (−48%)
  • On real trains: 6.18 min error vs 9.08 for the official timetable
